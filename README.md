# TimePlan

Prototipo web de organizacion del tiempo creado con React y Vite.

## Ejecutar localmente

1. Instala Node.js.
2. Clona este repositorio.
3. Ejecuta `npm install`.
4. Ejecuta `npm run dev` y abre la URL local que muestra Vite.

## Compilar

Ejecuta `npm run build`. Vite genera la version de produccion en `dist/`.

## Publicar

Puedes importar este repositorio en Vercel. Configura el comando de build como `npm run build` y el directorio de salida como `dist`.
